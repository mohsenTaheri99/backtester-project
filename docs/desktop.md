# Desktop build

The app is packaged in two steps: **PyInstaller** bundles the Python app (with
the built UI and data) into a folder with `GoldBacktester.exe`, and **NSIS**
wraps that folder into a single setup file.

```
desktop/
├── installer.nsi          NSIS script for the setup file
├── assets/
│   ├── icon.ico           exe + installer icon
│   └── icon.png           512 px source (both generated by make-icon.mjs)
├── scripts/
│   ├── build.mjs          the whole build (npm run dist)
│   ├── dev.mjs            dev mode: Vite + app window
│   └── make-icon.mjs      draws the icons
├── package.json           scripts and the app version
├── build/                 (generated) PyInstaller work + app folder
└── release/               (generated) the setup file
```

## Requirements (build machine)

- Node 22+ and `npm install` in `frontend/`
- Python 3.12+ on `PATH`
- NSIS 3 — `winget install NSIS.NSIS`. `build.mjs` looks in the standard install
  folders (or `MAKENSIS`), and also finds the copy electron-builder caches.

Customers only need Windows 10/11 with the WebView2 Runtime (preinstalled on
Windows 11 and on most up-to-date Windows 10 PCs).

## Scripts

Run from `desktop/`:

| Command | Does |
|---|---|
| `npm run dist` | Frontend build → Python venv → PyInstaller app → NSIS setup file |
| `npm run dev` | Vite dev server with hot reload inside the app window, backend from source |
| `npm run icon` | Regenerate `assets/icon.png` and `assets/icon.ico` |

### Build options (environment variables)

| Variable | Default | Use |
|---|---|---|
| `BACKTESTER_BUILD_DIR` | `desktop/build` | Intermediate files (~250 MB) — point at another drive if C: is tight |
| `BACKTESTER_OUT_DIR` | `desktop/release` | Where the setup file goes |
| `PIP_INDEX_URL` | PyPI | Package mirror, e.g. `https://pypi.tuna.tsinghua.edu.cn/simple` |
| `PYTHON` | `python` | Interpreter used to create `backend/.venv` |
| `MAKENSIS` | auto | Path to `makensis.exe` |

## What `npm run dist` does

1. `npm run build` in `frontend/` → `frontend/dist`.
2. Creates `backend/.venv` if missing and installs `backend/requirements.txt`.
3. PyInstaller on `backend/desktop_app.py`:
   - `--onedir --windowed` — a folder app with no console window. One-file mode
     would unpack itself to a temp folder on every launch.
   - `--add-data` for `frontend/dist` → `frontend/` and `backend/data` → `data/`.
   - `--collect-submodules app` — the FastAPI app is imported inside a function.
   - Excludes bokeh and its dependencies (see
     [Architecture → Why no bokeh](architecture.md#why-no-bokeh)), pywebview's
     non-Windows GUI backends, and tkinter / matplotlib / IPython.
4. `makensis installer.nsi` with the version from `desktop/package.json`,
   producing `release/Gold Backtester-Setup-<version>.exe`.

## Size

| | Size |
|---|---|
| App folder (installed) | ~86 MB |
| Setup file (solid LZMA) | **~27 MB** |

Most of the app is numpy + pandas (~45 MB) and the Python runtime. The earlier
Electron build of the same app was 147 MB, because it shipped its own Chromium.

## The setup file (`installer.nsi`)

- Installs **per user** to `%LOCALAPPDATA%\Programs\Gold Backtester` — no admin
  prompt. The install folder can be changed on the Directory page.
- Start menu and desktop shortcuts; a "Launch Gold Backtester" checkbox at the end.
- Registers in Windows **Settings → Apps** with version, publisher, size and
  uninstaller.
- Checks for the WebView2 Runtime first; if it is missing, offers to open
  Microsoft's download page.
- Closes a running copy before installing or uninstalling, and removes files
  from an older version on upgrade.
- Uninstalling keeps user data in `%LOCALAPPDATA%\GoldBacktester` (drawings, logs).
- Silent install for IT: `"Gold Backtester-Setup-0.1.0.exe" /S` (optionally `/D=C:\path`, last argument).

## Dev mode

`npm run dev` (`scripts/dev.mjs`):

1. Starts Vite in `frontend/` with `VITE_API_TARGET=http://127.0.0.1:8765`.
2. Waits for `http://127.0.0.1:5173`.
3. Runs `python desktop_app.py --dev --debug`: backend on 8765, window on the
   Vite URL, DevTools enabled (F12 / right-click → Inspect).

UI edits hot-reload. Backend edits need a restart (close the window, run again).
Dev mode uses a different origin, so its drawings are separate from the
installed app's.

## Releasing a new version

1. Bump `version` in `desktop/package.json`.
2. `npm run dist`.
3. Send `release/Gold Backtester-Setup-<version>.exe`. Installing over an older
   version upgrades it in place and keeps the customer's drawings.

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| "Windows protected your PC" | The build is unsigned. **More info → Run anyway**, or sign the exe and setup file with a code-signing certificate (`signtool`). |
| Setup says WebView2 is missing | Install the WebView2 Runtime from Microsoft (the setup offers the link), then run setup again. |
| Stuck on "Starting the backtesting engine" with a VPN / proxy on (0.1.0 only) | Fixed in 0.1.1. The readiness check used Python's HTTP client, which follows the Windows system proxy; a proxy without a `127.*` exception swallowed it. The app now reads uvicorn's `started` flag and never proxies loopback. |
| The app window shows an error instead of the chart | The backend failed to start; details are in `%LOCALAPPDATA%\GoldBacktester\logs\app.log`. |
| "Gold Backtester is already running" | A copy is open (maybe minimised). Close it first. |
| Drawings disappeared | Port 17800 was taken by another program, so the app used a different origin this session. Free the port and restart. |
| Build fails with disk or mmap errors | The build drive is full. Set `BACKTESTER_BUILD_DIR` / `BACKTESTER_OUT_DIR` to a drive with ~500 MB free. The installer itself also needs some free space in `%TEMP%` on the customer's PC. |
| `pip install` fails during the build | PyPI unreachable; set `PIP_INDEX_URL` to a mirror. |
| `NSIS not found` | `winget install NSIS.NSIS`, or set `MAKENSIS`. |
